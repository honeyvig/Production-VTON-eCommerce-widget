
# VTON Commerce – Production Virtual Try-On + eCommerce Widget

A **compliant, production-ready Virtual Try-On (VTON)** system that overlays garments without removing clothes,
altering bodies, or generating nudity. Safe for real users, brands, and marketplaces.

## Features
- FastAPI backend (GPU/CPU auto-detect)
- ControlNet pose + segmentation hooks
- Safe diffusion-based garment overlay
- Image + video try-on
- Embeddable JS widget (Shopify/Woo/Custom)
- Dockerized deployment

## Quick Start
```bash
docker compose up --build
```

## Compliance
- No cloth removal
- No body reshaping
- No sexual content
- Licensed/synthetic dataset structure
